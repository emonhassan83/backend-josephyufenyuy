# backend-josephyufenyuy

#### **Setup Instructions**

##### **1. Clone the Repository**

```bash
git clone https://github.com/bdCalling-Sdt-hub/backend-josephyufenyuy.git
cd backend-josephyufenyuy
```

##### **2. Configure Environment Variables**

- Rename **`.env.example`** to **`.env`**
- Update the file with your own credentials

##### **3. Start the Development Server**

```bash
npm run start:dev
```
